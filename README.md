PPLAB3VAR13

Графическое приложение для работы с таймером и секундомером.

Возможности

- Обратный отсчёт времени.
- Запуск, пауза, продолжение и сброс таймера.
- Установка времени с помощью цифровой клавиатуры.
- Быстрый выбор заданной продолжительности таймера.
- Работа секундомера с точностью до сотых долей секунды.
- Сохранение промежуточных результатов (кругов).
- Переключение между режимами таймера и секундомера.
- Анимация графических элементов интерфейса.

Используемые технологии

- Python
- "PySide6" — создание графического интерфейса.
- "time" — работа с временными интервалами.
- "QTimer" — обновление интерфейса и анимация.

Установка
```bash
pip install -r requirements.txt
```

Запуск
```bash
python main.py
```
